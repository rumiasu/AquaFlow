# 34 · 独立押金办理与实际收款

状态：当前新业务规格；2026-10-01 核对。

## 1. 产品规则

新增循环桶押金全部独立办理。选站、商品、数量及当前报价后单独付款；没有水单、没有实物配送，实际款确认后即生效权益。水票和水单不得夹带新押金形成混合支付。

资产责任始终留在原归属站。B 不因收本单水款替 A 建资产，也不能把收桶/站间折款登记成客户押金。

## 2. 渠道现状

现金由 A 核实实际收到后确认，未确认不生效。即便客户没有水订单，也允许 A 办理真实已收押金；这不代表客户已经获得水费赊账资格。

真实微信支付未接入，本地模拟可以验证联动但不能用于生产。付款结果未知时核实原笔，不重复购买，也不承诺已经领到桶。

## 3. 客户权利

成功办理后客户取得该站该商品权益，可先购票或订水；实物在以后订水领取。新容量先覆盖已有超占用，剩余容量才产生免回领取空间。

后续购水失败、缺货或退出页面不撤销已经实收的押金。未领权益可申请退款，无需交不存在的桶；已经领取的按正常申请制退还。

## 4. 记录与提示

每笔意图防重复，付款关联购买及批次。界面分别说明待核实款、已生效权益、实际持桶，不把“购买成功”显示成“水桶已到手”。站长待收款显示独立桶押金用途，不当作零张水票款。
