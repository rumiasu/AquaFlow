# 32 看板金额的现行口径

写给读经营看板的站长及维护报表的人。本文保留 2026-09-27 的决定；历史演练数字不作为当前统计结果。

## 1. 三个金额

`grossAmount` 是未取消订单的应收合计，`paidAmount` 是支付状态为已付的订单金额，`pendingAmount` 是未取消且待收款的订单金额。时间和站别过滤以服务端查询为准，营收归属使用结算站。

“已付款订单金额”不等于本站当前现金实收：水票是在购票时收到款，兑水时没有再次收款；接单站获得本单营收归属不代表它已经拿到 A 的合作款；无订单的押金、购票和上门收费也不能凭空出现在订单金额里。

## 2. 读数边界

收款、客户资产余额、站间约定报酬、已结合作款和工资是各自的事实。看板不能替代这些台账。部分消费退款后的订单仍可能保持已付状态，现行订单聚合不会自动变成净现金或完整售后净收入。

## 3. 外包和资产

押金留在归属站，不应视为履约站的销售收入。外包总报酬可以高于客户价，差额由外派站承担；现有经营报表尚未完整扣除这些补差、返还及桶款，不能依据旧毛利聚合声称全站利润已准确结清。

## 8. 已拍板结论

保留订单金额算法，把该指标明确显示为“订单已付款”，解释为已付款订单金额并说明不等于本站实收。该决定已经实施，不再询问是否改为流水聚合。完整现金收支或净经营报表是另一个目标，不能通过偷偷换一个指标的算法来宣布完成。
