## 可编辑边界与保存

| 字段／操作 | 平台选用商品 | 本站自定义商品 |
| --- | --- | --- |
| 名称、品牌、规格、类型、图片、说明 | 平台维护，本页不提交 | 同一编辑表单可改 |
| 本站售价、桶装水押金 | 可改站级覆盖；空白不改，0恢复参考值 | 显示当前有效金额；保存本商品售价／押金，并在同一PUT中清除旧站级覆盖，避免改完仍显示旧覆盖价 |
| 上架、优先展示、水票开关／价格／档位 | 可改本站字段 | 同表单可改 |
| 当前库存 | 独立命令、原流水／预留约束 | 同样独立命令，资料保存不覆盖库存 |
| 初始库存 | 选用流程原行为不变 | 仅新建时填写 |
| 其他操作 | 原“移除本站配置”保留 | “更多”内上报／停用 |

自定义商品价格归一仍保持当前有效金额；例如基础价12、旧本站价15，打开显示15，仅改名保存后基础价15、覆盖清空，有效售价仍为15，不会回落为12。用户修改金额时按新值保存。平台商品不走这条写入。

权限依据：后端以下文件均位于 `AquaFlow-backend/src/main/java/com/example/aquaflow/`；`controller/ManagerCatalogController.java:89` 只接收站级DTO；`service/impl/CatalogServiceImpl.java:246` 通过 `getOwnedById(productId, stationId)` 限定自定义修改，并在已有事务内写基本资料和本站配置；`dto/ManagerProductDTO.java:70` 已支持 `salePrice/depositPrice/priorityDisplay`。短缺依据 `service/InventoryLossService.java:21`：目标须小于当前实物，调整预留并写库存流水；不是财务亏损。本轮未更改这些后端约束。
