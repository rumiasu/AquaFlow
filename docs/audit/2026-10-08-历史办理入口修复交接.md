## 行为与边界

- 退桶审批页默认读本站未结退还申请：新模型 `APPLIED / APPROVED / RECEIVED`，历史路径待收桶、待退款及交付待核实。全部历史只读 `type=2` 申请，按申请 ID 降序，每页 50 条；批准待交接不会再被其他类型桶流水挤出。页面有筛选、更多/重试、申请编号查询和返回清单。业务待办页增加常驻的完整退还清单入口。
- 拒付页默认读仍有原款限制或本站现有纠错责任的案件；全部历史按订单 ID 降序，每页 50 条，支持订单编号定位，包括已经关闭的原案。可见范围始终为登录站是资产站或债权站。未新增判断或写权限：撤销仍认债权站，解除仍认资产站。
- 首次/刷新失败不显示成已核对的零事项；翻页失败保留已读行和原游标，可重试。页面验证站别、筛选、游标、顺序、结构；过期读取与身份切换后的回调不能覆盖新清单。冻结弹窗加入当前读取与登录身份保护。
- 拒付未知结果继续保留原 `idempotencyKey / expectedVersion / reason`，另外保存按员工、站别隔离的原订单定位。再次进入先读原案，案件已经关闭或新增历史超过 200 条也能核对原回执；不生成新纠错请求。
- 旧列表接口保持兼容。原审批、安排版本、收费授权、免费原安排免二次确认、退款资格、资金及资产写入口均沿用。原业务提醒查询的时间口径不改，完整未结清单为独立入口。
