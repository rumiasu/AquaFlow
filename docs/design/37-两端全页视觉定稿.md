# 两端全页视觉定稿

2026-10-22，按用户确认的首页合并方案落实。范围为两端 app.json 当前所有路由、共享状态和既有弹层。逐页实施及验证以[覆盖清单](../audit/native-ui-20261022/README.md)为准。本轮不改变支付、退款、桶资产、权限、状态机及后端接口。

## 1. 当前视觉

浅灰白页面底 `#F5F6F7`、白色内容区、功能蓝。主动作采用 `#1264D6`，比候选 `#1677FF` 稍深，保证白字可读；浅蓝 `#EAF3FF` 用于选中与信息区。正文 `#182230`、常规 `#4B596A`、辅助 `#637083`；占位色不承载费用、地址或警告。价格以深色字重为主，仅静态商品海报允许少量暖橙。

保留兼容 token 名，历史 gradient 变量仍是纯色。常规圆角 8/12/16/20rpx，白区使用分隔线和留白，减少卡套卡与装饰阴影。双端文字功能色同义。列表允许长名称、地址及金额换行，触控不以截断信息换密度。顾客操作目标至少88rpx；配送主要动作96rpx，底部安全区保持。

## 2. 顾客购买

首页依真实数据排序：水站及后端营业说明、收货地址、当前订单、照上次订、选水、桶与押金。无进行中订单且无可复购订单时，商品海报放在选水之前；存在进行中订单或可复购订单时，海报排到选水之后，让熟客直接看到商品数量操作。首页没有状态演示切换，也不建立个性化系统。

“再订一单”只传原订单 ID，直接进入既有确认页。确认页重新取原单商品数量和地址、当前商品资料及服务端报价，不累加购物车、不复制历史价格、库存或押金，不直接创建订单或付款。复购以原订单归属站为定价和资产站，外派履约站不代替它；切站确认与原读取绑定账号及页面周期，后台返回重新核实未完成的读取/确认。原地址已删除时沿用既有地址选择逻辑，确认页可改地址和数量，再核算当前报价。重复点在导航未完成时忽略；导航失败提示后可重试。

静态海报在本站有商品时显示，使用实际商品名、规格与本站零售价；商品图优先目录图片，无图或图片失败时显示文字占位，中性桶图明确“商品示意图”。场景图与商品图的具体边界见文末。点击进入本站商品目录。没有轮播、弹窗营销、虚构折扣、销量、年资、送达保证或健康承诺。海报精细美术可后续独立优化，不以此阻挡订水。

确认页保持地址、商品、支付方式、费用、备注、确认动作。水费、新增押金、配送与楼层费、本次总价、票不足/库存/范围限制、未知结果与恢复入口常显。费用只读同一次服务端报价；系统按已付容量及业务占用核算，不提供“勾选有空桶免押金”。长次要解释折叠，站别资产边界常显。

## 3. 员工任务

站长页面以待办、当前客户资产、现有商品库存与经营事实为主，已有配置先于新增表单；配送以目的地、电话、桶数、收款状态和下一步动作优先。财务待收金额与异常任务前置，付款/退款责任和不可逆后果紧邻操作，未知不显示成零。原始技术记录可以展开查看，但金额与责任不折叠。

2026-10-22 独立复核：站长仅一项待办时改为整行呈现数量、事项和金额，避免沿用四分之一列造成空白；多项布局、数量和经营口径保持。顾客选站列表分清读取中、失败重试与真实空结果；通知弹窗在离页或换账号后不继续，也不沿用新会话标记已读。结果页保存模板仅说明管理用途，不承诺首页自动使用。

表单、列表、详情、协议、登录及账户页逐页检查，不为了数量强行改变业务结构。E/H 技术术语按已有字段含义翻译为已领桶/水站暂存等，不把实物、权益、活动占用混成一个数。保留已有权限、报价、确认与凭证要求，不增新流程。
