# 34 · 随单与独立押金办理、实际收款

状态：当前新业务规格；2026-10-03 核对。

## 1. 产品规则

新增循环桶押金支持两条路径：随水单新增押金与水款同次付款、分项记账；或者选站、商品、数量及当前报价后单独购买。两者都在实际款确认后生效，付款不代表已拿实物。水票不能支付新押金，水票与现金/微信混合支付仍不支持。

资产责任始终留在原归属站。B 不因收本单水款替 A 建资产，也不能把收桶/站间折款登记成客户押金。

## 2. 渠道现状

现金由 A 核实实际收到后确认，未确认不生效。即便客户没有水订单，也允许 A 办理真实已收押金；这不代表客户已经获得水费赊账资格。

真实微信支付未接入，本地模拟可以验证联动但不能用于生产。付款结果未知时核实原笔，不重复购买，也不承诺已经领到桶。

## 3. 客户权利

成功办理后客户取得该站该商品权益，可先购票或订水；实物在以后订水领取。新容量先覆盖已有超占用，剩余容量才产生免回领取空间。

单独购买押金后，后续购水失败、缺货或退出页面不撤销该资产。随水单实收的新增押金，在已付未交付取消时仅退款并终止本单新增批次空闲份额；其他资产或已被占用的份额保留。未领权益可申请退款，无需交不存在的桶；已经领取的按正常申请制退还。

## 4. 记录与提示

每笔意图防重复，付款关联购买及批次。合单新增押金须明确确认逐商品数量和本站单价；旧容量被占用可等待或另买，不静默加收。现金到门须收齐水款及押金再激活并交付，失败一同回滚。界面分别说明待核实款、已生效权益、实际持桶，不把“购买成功”显示成“水桶已到手”。站长待收款显示独立桶押金用途，不当作零张水票款。

退款预览与执行共用空闲资格：已覆盖实物、其他订单或退还占用的新增押金保留，并显示保留金额及原因。员工对随单新凭据退款须回传所选预览金额；锁后重新计算实际退款，金额变化则整笔回滚，重新预览确认后才能登记。无随单新凭据的历史退款保持原路径，不替旧请求猜金额。

同一原款的消费与押金退款由原付款行锁串行保护，先锁订单与原款，再锁桶账。外层事务等待行锁之后，以独立只读事务的最新提交凭据与外层新增凭据按各自主键合并核验上限，不复用旧快照，也不锁非唯一退款索引的空区间。同次多商品押金退款逐条计入退清判断。
