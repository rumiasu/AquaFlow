## 6. 明确保留的未完成项

- **真实支付暂停**：离线适配器/匹配器未接入 Spring Bean、HTTP 回调、服务器付款映射、商户调用或持久幂等账本。现有 [范围决策 §9.3 C-01](../design/16-范围决策与实施路线图.md) 等待拍板正本不因本地通过而关闭。
- **重复键 P2 仍未解决，范围已核正**：匹配器的严格解析和现有 `signedRefundEventAndDuplicatedEnvelopeEventTypeAreRejected` 测试证明外层通知的重复 `event_type` 被拒绝；它们不能证明解密原文没有重复键。`WechatPayNotificationAdapter.java:85–90` 先调用 SDK `parse(request, JsonObject.class)`，再 `resource.toString()`；Gson 已将重复字段合并，匹配器第 38 行收到的是规范化字符串。2026-10-04 离线探针用随机内存 RSA/AES 密钥加密并签名含两个 `mchid` 的原文：直接严格解析拒绝，经过真实 SDK 后严格解析却通过，且匹配器接受最后一个匹配的 `mchid`。这确认原问题仍在解密正文链路；此前本记录“当前匹配器已严格拒绝重复 JSON 键”的整体结论过大，现已撤回。未修改支付代码，也未接真实资金。探针及结果仅保留本机 `.gradlehome/codex-github-handoff-20261004/duplicate-resource-probe-v2/`。
- **生产迁移未做**：v74 和已有迁移只在自建隔离测试库执行。真实业务库升级须另行确认、备份并按 SQL 清单操作。
- 未取得实体手机或其它屏幕/安全区证据，未证明完整生产正向启动，当前归档代码的完整 CI 后端结果已在 §8 独立列示；定向、GUI 与此前历史全量证据分别保留，不混加计数。
