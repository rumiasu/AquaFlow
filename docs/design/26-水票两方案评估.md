# 26 水票方案的现行结论

写给维护水票设计的人，保留已作出的取舍。现行购票、使用和退出规格在 [19](19-水票档位与批次单价.md)，本文不再同时维护另一套计算规则。

## 1. 已定范围

首期不做混合支付。一张消费单选微信、现金或水票中的一种；票不够时不能先扣票再留下现金差额。新增桶权益单独购买、实际收款后生效；消费单不顺带收新押金。

购票先要求客户在本站、对应商品上有有效桶权益。权益购买不附带一单水，下次订水领取新桶；未领取容量在回桶计划中免回收。它解决购票资格和押金资金分开的问题，不能被重新解释成“水票可以任意跨商品兑换”。

## 2. 两类报价设置

商品套餐与统一折扣设置解决购票报价的组织方式；账户仍按客户、站、商品隔离，实付价值仍记录到票批次。所谓统一折扣不是站级通用现金钱包，也不是所有水种的兼容票。

使用水票时没有第二次向客户收取票款。消费金额、票批次价值、实际现金以及站间约定报酬有不同用途，不能互相替换。票覆盖的服务费用按已定规则处理，不能因不同付款方式擅自调整客户原成交责任。

## 3. 不再沿用的旧结论

早期文档中“无订单在线购票不能退款”的全盘限制不再是当前目标：v71 提供有真实原款批次的未用票退出，未知来源、赠票和历史迁移批次不伪造原渠道退款。细则见 [19](19-水票档位与批次单价.md)。

混合支付和跨商品票不属于本期；未来明确扩大范围时才重新决定差额、原路回补和售后拆分，不能把曾经的候选方案当作尚未做完的承诺。
