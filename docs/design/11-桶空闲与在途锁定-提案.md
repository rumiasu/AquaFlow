# 11 桶空闲与执行占用：历史提案的结论

写给追溯桶模型演进的人。本篇保留提案编号，**不再作为当前规格**。当前按数量占用的模型见[领域模型](../architecture/02-领域模型.md)和[业务流程](15-业务流程地图.md)。

## 1. 提案解决的问题

客户同一份桶权益不能在前一单未交付时再次抵用，也不能一边执行订单一边退掉已分配权益。早期按“客户所有桶整体锁定”的设想会误阻断其他闲置权益。

## 2. 当前采纳部分

v71 按数量建立订单或退桶用途的占用：一份被使用的权益被锁定，其他闲置份额仍可使用。实际支付生效的权益与桶是否已经领到分开记录，领取容量在下次交付时免回桶。

## 3. 未采纳部分

没有逐实体桶的全局状态机、逐桶编号、整账户冻结式忙闲模型，也没有因配送中状态自动把客户所有资产禁用。不能把本篇旧提案中的状态或字段作为待实施清单。
