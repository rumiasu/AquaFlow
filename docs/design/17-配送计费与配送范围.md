# 17 · 配送范围、消费费用与服务承诺

状态：费用规则已实施，时间承诺尚有决策缺口；2026-10-01 核对。规则入口 `DeliveryFeeUtil`、`DeliveryFeeService`，报价和下单同源。

## 1. 定价方和快照

归属站确定客户水价、配送费及楼层费，下单记录当时结果。外派或改派不重算客户价；履约站取得约定费用及报酬。费用不并入水费或押金，新押金独立购买。

2026-10-11 客户结算页的报价绑定请求时的客户会话、水站、地址快照、商品数量和支付方式。地址未加载/核实失败时暂停报价；地址返回、重选或同编号编辑先失效旧金额和确认，再按当前地址报价。较旧请求及隐藏/卸载页响应不能恢复可提交状态；返回页先应用选址结果，未完成的地址读取重新加载。新建请求和确认入口共同校验报价上下文，已提交的原请求恢复仍重放原快照。

该绑定消除客户端地址竞态，不提供服务端报价锁价。建单仍按当前 `addressId` 与当时配置重算费用，没有报价编号；付款丢弃客户端金额、采用订单金额。建单后的费用 warnings 为“下单成功，请注意”的无取消告知，关闭后继续原付款流程，并非总额变化的再次授权。报价到建单之间若地址记录或站级计价在服务端变化，仍可能重算为不同总额；本次不改变楼层费政策或支付业务，也不以每次提交重报假称消除该窗口。

## 2. 起送门槛

桶数/水费条件取或，默认 WARN 提示；REJECT 拒绝和 FEE 加收由站长显式配置。未知/非法模式不当成默认硬拒绝。非循环桶订单不套桶数条件，按适用金额条件判断。免起送特权按本站客户生效，不自动免配送费。

## 3. 范围和配送费

按站到地址直线距离及站级配置判断。坐标缺失时不假算超范围；默认提醒，硬拒绝和远程加费由站长选择。免配送桶数或金额达标免基础配送费；门槛都未配置不等于一直免费。未知电梯/楼层不凭猜测多收费。

2026-11-04 配置编辑采用快照校验：读取返回 `snapshot`，保存必须原样携带 `expectedSnapshot`。快照区分“尚未配置”和已保存配置，并覆盖水站及全部计费项；默认显示值不代表已保存。保存事务先锁定水站记录，再当前读取配置并比较快照，冲突时保留另一会话的配置、提示刷新核对，不自动重试覆盖。锁定已存在的水站记录也保护首次并发创建，因此无需新增版本列或数据库迁移。旧客户端未携带快照会被拒绝，需要更新员工端后再编辑配置。

### 3.1 客户找新站的发现范围（2026-11-07）

客户找新站使用 `GET /api/stations/discover`（兼容单数 `/api/station/discover`），参数为 `lat`、`lng`、`province`、`city`，返回站点数组。该公开读取受公开限流保护；只读取硬营业且非待上线的候选站，一次关联配送配置，不修改任何绑定、订单或资产。

2026-11-09 客户端选站打开时，先重读当前账号地址列表，以本登录周期正在使用的地址 ID 优先、默认地址次之；有合法坐标即带坐标按距离查找，不要求先手选城市。地址无坐标时只用该地址自己的省市明确兜底，不借用另一地址的坐标；没有可用地址时保留地图选点和城市选择。手动变更范围优先于未完成的自动读取，关闭、离页及换账号使旧读取失效。地址 ID 只保留在当前登录周期内，坐标重读，不新增持久地址副本。找站不自动替客户选站，也不改变既有下单站或历史资产站。

- 已配置正数配送半径：必须有双方完整、合法的坐标，直线距离小于等于该站半径才可发现；同城不能放宽此条件。距离未知时不列出，即使该站超范围计费模式为 WARN 或 FEE。
- 半径未设置或为 0：距离小于等于 10 公里，或者能够确认省市相同，满足任一即可。距离排序使用未舍入米数，展示距离保留一位公里小数，无法计算距离的同城站排在后面。
- 没有有效坐标且没有完整可识别省市时返回空列表，不回退全国列表。未提供定位时可只按省市查找；显式提供残缺或越界坐标时返回空列表，不能通过把未知坐标当作 0 获得候选。

现有 `station` 只有自由文本地址，没有结构化城市列，因此同城只认可完整行政区前缀：一般为完整省/自治区名称加市、自治州、地区或盟名称，直辖市按其完整名称识别。跨省同名不合并，自治州（含“州”简称）/地区/盟后又追加县级市等复合城市参数不作为同城条件，不使用地址中任意位置的城市关键词，也不从坐标猜测城市。旧地址省市缺失、简称或非标准格式可能漏出同城候选；这类站仍可凭有效坐标满足距离条件。此次不补写旧地址、不新增字段，无数据库迁移。

这只是客户发现新站的规则，不替代本节原有下单范围计费。报价与下单仍按收货地址和 WARN/REJECT/FEE 配置计算，未知距离保持原处理；`/public` 和员工申请绑站的 `/search` 保留既有行为。历史服务站、订单、资产站查询及退桶、退押金、退票等既有入口不经过发现过滤，客户位置变化不会删除或隐藏其历史关系和资产。

## 4. 楼层费

地址明确有电梯、楼层未知或未超免费层时不收对应楼层费；电梯未确认时不当无电梯，提示核实。按单/按桶模式来自配置；给配送员的楼层补贴是另笔成本，不能混入客户收费列。

## 5. 收桶服务

资产申请的独立上门收费另行批准、客户确认及实际支付；到店、顺路或未领容量不收独立上门费。未履行服务退款另记原款，不净扣押金，也不因消费水费退款自动取消资产安排。

## 6. 预约和承诺

当前预约为自由描述，没有完整的时段承诺、延期确认及超时退出规则。起送/范围配置只表达是否接及如何收费，不等于接单站确认某时刻送达。

时间填写只取可选期望或备注，不自动形成站方承诺，不新增复杂预约审批；唯一正本见 [design/16 C-05](16-范围决策与实施路线图.md#c-05预约时间是请求还是站方承诺超过承诺如何退出)。既有计费与取消/退款规则保留。

## 7. 验收

报价与下单总金额及警告一致；只数适用循环桶数量；外派不改客户快照；未知坐标、电梯及费用配置不假判；消费费用和资产款退款后果分别正确。已有测试结果不等于时间承诺已经定义。
