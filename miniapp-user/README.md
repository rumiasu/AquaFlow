# AquaFlow 客户小程序

客户在这里选择水站、订水、购买水票、查看桶与押金、申请退还和查询订单。它与员工端是两个独立微信小程序，登录配置不可混用。

## 主要路径

| 客户意图 | 流程 |
|---|---|
| 首次使用循环桶 | 选择站和商品 → 独立交押金 → 等实际收款确认 → 再订水领取桶 |
| 提前购买水票 | 已有该站该商品权益 → 查看档位 → 独立付款 → 实际款确认后入票 |
| 再订水 | 选地址、商品、数量 → 查看费用及可用权益 → 单一方式支付 → 等待配送 |
| 结束用桶 | 查看可退数量和原押金金额 → 在线申请 → 确认站长安排 → 实际交桶 → 查询实际退款 |
| 处理异常 | 查看可读原因和原订单；消费售后与退押金分别办理 |

买权益成功不代表拿到了桶，也不代表随后买水成功。付款未知时重试原意图，不能引导客户重复付款。水票不足、权益占用、缺货等待和资料加载失败各自说明原因，空列表不等于加载成功。

## 范围和展示

权益、水票和押金按站及商品隔离；不自动跨站使用或换成另一种商品。权益数量和客户实际持桶分别显示。新增权益只对尚未领取部分免回桶，旧有桶换水仍核对回收。

当前不支持混合支付。客户有一个桶权益可以多买张水票，但同一份权益不能同时分配给两张进行中订单。退还申请占用对应数量，不把闲置权益一并封锁。

## 开发与联调

用微信开发者工具打开本目录。页面注册以 `app.json` 为准，API 基址以 `config/api.js` 为准；生产地址仍需正式配置。客户端 AppID 与 Secret 必须来自本端应用。

局域网联调见[本地运行说明](../docs/operations/02-本地运行-笔记本当服务器.md)。模拟支付仅供开发，不表示真实支付可用。当前流程测试模拟 `wx` 和网络回调，不能替代开发者工具及真机验收。

业务规格见[流程地图](../docs/design/15-业务流程地图.md)、[桶与资金模型](../docs/architecture/02-领域模型.md)、[水票规则](../docs/design/19-水票档位与批次单价.md)。
