# 拒付复核与恢复：安全实施建议

状态：2026-10-05 的一页实施建议，本批未新增业务命令、状态、字段或自动作业。已定方向与剩余产品问题只维护在 [design/16 C-03](16-范围决策与实施路线图.md#c-03拒付错判免债与解冻的结案权)，不在这里另建 TODO 正本。

| 动作 | 可以先明确的边界 | 实施前仍须解决的规则 |
| --- | --- | --- |
| 人工复核 | 债权站核原单、原款、客户陈述与实际交接，追加复核人/时间/依据 | 不用复核备注暗改债权金额或全客户冻结 |
| 撤销错判 | 独立于收款和免债，保留原判断与撤销凭据，不恢复终态订单 | 明确该判断实际产生了哪些限制；不能解除另一站或另一争议的限制 |
| 延期 | 单独记录期限和约定，余额不因延期减少，延期不等于已收款 | 不擅自定义复核时限或冻结自动过期策略 |
| 真正免债 | 独立具名审计动作，不能创建 PAID 流水冒充实收 | 部分免债范围/金额边界待定，禁止目前新增任意金额扣减入口 |
| 实际收款 | 继续既有真实收款凭据与 CAS，避免同一款重复入账 | 不能拿客户异议或站长点击复核当作收钱 |
| 资产限制解除 | 资产归属站核本次冻结原因，解除与赊账资格分别处理 | 冻结金额、商品范围、争议间叠加关系与期限见 C-03；不批量清标记 |

实现应使用显式命令和事务：会话身份判权→锁/当前读该凭据→核期望状态与已有处理→核金额及约束→写一次事实与审计→提交。幂等键按责任站/对象/动作隔离；同键不同内容拒绝。失败整笔回滚，不以更新0行冒称成功，不人工 SQL 覆盖已有判断、债权或冻结凭据。

无库先准备身份/责任站、动作不可混用、重复键、期望状态及“只复核不动金额”的反例；规则定后再做部分免债竞争、已收/已免余额、跨站多争议与解冻边界的真实事务回归。当前没有这套完整结案能力；本建议不是已完成实现，也不给自动免债或解冻授权。

这项未定工作不阻塞已经明确的少桶原因选填、期望时间备注、实际退款只读展示或离线备份准备。
