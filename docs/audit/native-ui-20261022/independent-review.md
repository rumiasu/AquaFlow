## 五条设计建议

1. **熟客页需要更明显的办事节奏，已小改。** `home-repeat-confirmed__VISUAL.png` 的复购卡与海报叠加，让首个数量控件落到首屏结算栏下方；新客图没有这一问题。现改为熟客先选水、海报后移，新客仍保留海报。收益是改数量与直接复购同样容易找到；代价是熟客海报曝光下降，不涉及营销模块或全站布局翻转。
2. **站长待办按内容多少用空间，已小改。** `final-11__VISUAL.png` 只有“2 待收款 ¥86”却只占横排四分之一，空白比信息更显眼。单项改整行，数量—事项—金额沿一条阅读线展开；多项保持原布局。收益是责任和金额更好扫读；代价是单项/多项排列不同，后续仅需原生窄屏确认换行，不改经营口径。
3. **海报色调合拍，语气略偏通用广告，建议下一步讨论。** 最新四张首页图中的蓝色与UI协调，但光亮水桶、水花和大面积深蓝更像商品广告；周围地址、金额、操作是朴素社区服务界面。建议只对海报素材做一版更平静的水/桶构图，或在确有授权实拍时使用真实水站场景，继续保留现有文字和真实商品层。收益是社区水站辨识度及整体协调感；代价是素材制作与对照选择。本轮不改全局蓝、不换导航，也不擅自移除现有海报。
4. **商品差异最好交给真实商品图，建议先补内容。** 老客图首款与目录的中性蓝桶只能说明“桶装水”，辨认仍依赖名称、规格、价格。应优先用现有商品图配置录入真实标签/包装图，并统一留白和物体比例，缺图继续明确示意。收益是减少同类SKU看错；代价是采集、授权、压缩及维护，不能用生成标签冒充品牌实拍。无需新增模块，也无需把员工工作页改成大图货架。
5. **部分任务页有“表单说明书感”，可做局部减法，不宜全站压密。** `final-14__VISUAL.png` 导航“确认送达”下又有独立大标题卡，随后“本次送货”才开始地址卡；相反地址/电话/桶数/付款事实本身清楚。可讨论将顶部重复标题合成紧凑的原订单标识+一句核对提示，把空间让给回桶及收款；保持正文大小、警告和动作触区。收益是更直接、少一层框；代价是需原生验证长单号与系统字体放大，本轮未仅凭偏好改它。

不采纳全站换色、统一缩字/缩按钮、全部取消留白、生活方式大图、营销数据编造等方向：它们没有解决本轮真实任务问题，且会削弱现有可读性或信息可信度。后三项建议不阻交付，也不是已承诺的新业务。
