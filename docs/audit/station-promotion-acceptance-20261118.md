# 站内商品促销验收（开发分支）

本次可独立合入的是 **v98 后端、迁移和回归**。它为小程序提供本站实价；开发分支的这个提交不包含站长海报编辑界面，不是发布包。不得把本记录视为生产迁移或微信真机验收。

## 可比对的经营结果

- 站 A 日常价 20.00 元、活动价 15.25 元：站长目录、顾客目录和详情读到相同活动价；买两件的报价和订单水款都是 30.50 元。邻站仍使用自己的原价 23.00 元和平台商品资料。
- 调整站 A 日常价到 21.00 元、结束活动后，新报价是 42.00 元。已下单的水款仍是 30.50 元，明细保留原单价 15.25 元，以及当时的商品名称和规格。
- 零售活动不改水票价、桶押金和实物库存。清空本站覆盖会恢复平台资料。并发改规格与改价不得互相覆盖；非法组合整笔不写入。
- 平台下架（0）或停售（2）后，即使旧购物车仍保留商品，报价也不再计入这行促销金额，与可售列表和创建订单的结果一致。站内下架只影响本站。
- 保留本站历史库存或票据记录不代表获得其他站商品的可见权或销售权。

## 如何重验

使用专属的空白 MySQL 测试库，先核对回环地址、端口、库名和备份。旧结构的 `inventory` 表执行 `migration_v98_station_product_promotion.sql` 两次，每次应恰有三个新增字段。**不要对已有业务库运行集成测试**，这些测试会清理测试目标。

在已经按仓库指南准备好隔离库后，于 `AquaFlow-backend` 执行：

```sh
./gradlew test --tests '*StationProductPromotionIntegrationTest' --tests '*CatalogOwnershipIntegrationTest' --tests '*InventoryStaffProductIntegrationTest' --tests '*TicketPackageAndLotIntegrationTest'
./gradlew bootJar
```

本轮针对干净开发基线实际运行上述四组 HTTP/MySQL 集成测试，共 26 项，全部通过。另在目前含海报界面的本机工作区复测了已保存价格、异步回调、首页购物车与商品编辑；这不等同于在手机上测试保存和转发。
