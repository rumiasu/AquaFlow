# AquaFlow 员工小程序

站长和配送员共用此小程序。站长负责经营和调度，也可以自己配送；配送员只处理派给自己的任务。角色、本站关系和业务状态共同决定可执行的动作。

## 日常工作

| 角色 | 工作 |
|---|---|
| 站长 | 商品与库存、客户及线下付款授权、分配/外派、收款、售后、退桶审批、站间往来、员工计件与工资台账 |
| 配送员 | 接受派给自己的单、查看收货快照、配送、登记实际回桶及收款、报告异常、申请协作 |

未分配订单属于站长调度范围。配送员不能通过猜测订单 ID 接走未分配任务。只有已付款订单和合法货到付款订单进入履约列表。

## 外派及售后

A 发出外派后，B 接单前确认本单完整报酬及净桶安排；B 接受后负责本单服务和客户沟通。客户在 A 的押金和水票不搬到 B。跨站只提供履约所需订单快照，不开放 A 的客户档案。

站长在订单详情分别办理水费/服务费售后；退押金必须走资产申请。拒付确认不能直接扣押金，相关 A 资产冻结须 A 核实。业务待办集中查看缺货、超时申请、拒付、桶交接、站间返还及未使用真实水票退出。

收款页面区分订单消费、水票、独立押金和上门收桶费。点击确认是登记核对后的实际到账；“已收到桶”和“已退押金”也是两个不同动作。

## 运行与维护

微信开发者工具打开本目录；与客户小程序分别配置 AppID。页面和底栏以 `app.json`、`custom-tab-bar/` 为准，新增底栏项必须一起调整。生产 API 地址需正式配置。

提醒目前为应用内状态与红点，不宣称已发送外部推送。工资发放和站间结清登记实际线下动作，不执行平台打款。开发说明见[贡献指南](../CONTRIBUTING.md)，业务规格见[文档入口](../docs/README.md)。
