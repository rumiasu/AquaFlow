## 最终行为

- 水票统一为套餐。开启水票时给出可修改的10张待填价草稿，可改成1张；顾客按份数购买，后端按有效套餐核价。旧价格兼容不会复活已删除或下架的1张档；已存在订单和原幂等请求继续识别原意图。
- 商品库存和流水共用一个原生 `page-container`。保留原入库凭据时，继续发送原数量和原请求键；新商品的成功回执不能清掉其他商品的原凭据。库存转流水不因延迟离开事件误关，关闭后页面可滚动。
- 起送条件、配送范围、配送费、楼层费直接进入上线准备。输入不自动跳项；点击完成才推进；只有手动保存且回读一致才显示完成。不限保留左侧数值草稿；退出取消保留草稿。总览按模块分组，“怎么做”保持一行，较长内容以“等”收尾。
- 资产页突出水票数量，押金和桶有明确入口。资产状态放在标题区域，归属说明集中到选站弹层。业务JS未改，未知/失败资产不显示为0，查看历史站不会改下单站。
