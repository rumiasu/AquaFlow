# 14 商品图片和目录素材

写给维护商品资料的人。本文说明当前素材能力和发布边界，不作为市场研究或价格依据。

## 1. 图片负责识别商品

图片须对应实际销售的品牌、品类和包装，不能用相似包装冒充商品。客户成交依据仍是商品身份、规格、站级价格与订单快照；品牌图片不定义桶兼容关系，也不替代客户资产规则。

通用商品与站属自定义商品沿用 [12](12-商品与库存重构.md) 的可见范围。没有平台运营前端，不能将维护设想描述成已可由平台管理员操作的页面。

## 2. 当前提供方式

后端保留商品图片对象引用和预设图片入口，图片访问由存储服务生成可用地址。`ProductImageKeys` 提供 `barrel-neutral-template` 中性示意图映射，与下述模板使用同一资源；它不是品牌实拍图库。无法访问或没有图片时应使用明确的占位展示。

商品图可以跟随商品资料维护，但不能让外派订单暴露归属站的库存、进货成本或客户档案。历史订单识别依赖订单快照，不能只靠随时可替换的图片。

## 3. 素材发布边界

早期自制图片已撤下，不恢复或重跑旧脚本。本轮用户明确允许原创中性桶装示意图：无商标、无标签、无仿造品牌包装，品牌文字独立显示，站长及顾客图片旁标明“商品示意图，包装以实物为准”。它不冒充品牌实拍，也不说明实际桶型兼容。正式品牌素材仍须逐项核对来源和可发布依据；官网可查看不等于可商用再分发，本轮没有抓取官网商品图打包。

早期文档中的品牌名单、所谓实采价格和市场习惯没有在本轮取得可复核采样证据，因此不再列为设计事实。水价由水站配置，押金、票和配送规则由本项目明确的决策决定。

## 4. 后续维护

补充真实图片属于素材交付和验证，不是新的资金模型决策。发布前核对实际目录、对象引用、两端图片加载与无图回落；没有完成这些核对就不能把图片能力标成上线验收通过。

## 5. 2026-10-21 首批可编辑水商品模板

站长“商品与库存 → 全部目录”提供三款普利思基础资料，不声称市场份额或销量排名。默认名称和水种分别依据官网[饮用纯净水](https://www.pulisi.com/product/128.html)、[饮用天然泉水](https://www.pulisi.com/product/130.html)、[饮用天然矿泉水](https://www.pulisi.com/product/129.html)。厂商[2019年验收资料](https://www.pulisi.com/data/upload/file/20190619/1560920806662495.pdf)分别记载三种18.5L产品及另有12L矿泉水；18.5L只作为可编辑起点，不保证当前全部在售包装。表单提示以实物标签核对，可改名称、品牌、规格和说明，不用旧脚本的18.9L、促销、空桶互换或价格推断代替事实。其它品牌证据不足，暂不加入。

“使用模板”优先复用公共目录里品牌、水种、容量均精确匹配的可用商品；多条同款时回目录让站长核对，不自动猜。未找到时带入本站自定义商品草稿；“按实物修改”始终可开可编辑草稿，即使公共目录已有同款，也不擅改公共SKU身份。复用已有 `GET /api/manager/catalog`、选用接口与 `POST /api/manager/my-products`；不新增表、后台或自动种子写入。

模板只带名称、品牌、水种、可编辑容量、桶装分类/桶单位、说明和图片。售价、桶押金、实际库存为空，保存前需站长明确填写；库存可确认为0，默认不上架、不开水票、不设票价，不把未确认的空值当经营零值。选择模板只操作本地草稿；精确复用公共品时只选入本站且保持未上架，经营设置仍由站长确认。公共品已有参考值不被模板覆盖。另开模板使用独立图片草稿，原未知上传记录保留，旧选图回调不能覆盖新模板。

示意图为本次内置 imagegen 原创输出，最终两端同路径 `assets/product/barrel-neutral-template.webp`，512×512、11942字节，SHA256 `9061e9df9ceb863a99ac4bf73ab2239403d94812abc7c7a35e74d85d5617bab2`。生成提示：单个浅蓝半透明循环水桶、纯蓝桶盖、暖白背景、居中完整轮廓、轻柔阴影、友好的3D插画；无品牌、标签、包装仿制、文字、容量、价格或水印。只缩放转码为WebP，不对品牌官网图加工。后端现有 `ProductImageResolver` 原样返回以 `/` 开头的包内路径；无需COS或新增存储凭据，两个小程序都必须包含该文件。

本批未插入真实水站数据，未上传体验版或部署。更新范围及操作准备见[受限体验交付说明](../../deployment/limited-trial/README.md#water-templates-20261021)；当前离线验证与准确提交CI只认本批交付回执，不把素材就绪当作原生或手机通过。
