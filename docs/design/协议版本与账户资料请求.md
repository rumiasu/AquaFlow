# 协议版本与账户资料请求

本文件说明本轮专属实现、默认关闭边界与统一验证交接。产品决定唯一正本仍为 [范围决策 §12 C-09/C-10](16-范围决策与实施路线图.md#c-09隐私协议主体版本与登录同意规则2026-10-05)。本轮依据实际源码重新检查，未把历史审查或旧 CI 结果作为本轮结论。

## 盘点与本轮结果（2026-10-08）

盘点时两端协议页为内联占位稿，登录提示却称“登录即代表你已阅读并同意”；2026-09-24 取消强制复选框的裁定存在，但 DTO 只有 code，服务端没有正文版本或确认记录。本轮保留无复选框的主动点击体验，并将未启用草稿与正式版本告知分开：草稿登录不携带正式确认版本，不生成接受事实。正式正文未确认，未发布。

原有 `/api/customer/account/closure-check` 聚合本人全站事实，读取失败或历史疑义给 complete=false、clear=false，不删除或改变资料。资料编辑已有昵称/手机号更正。本轮新增本人资料请求登记和记录页，默认关闭；开放后也只生成 SUBMITTED（已登记，待人工核实），没有处理完成、导出下载、删除、匿名化、注销、令牌停用或权限扩展命令。

## 正文与确认凭据

`src/main/resources/agreements/index.json` 指向打包正文，摘要按 UTF-8、LF 换行计算 SHA-256。版本为 audience-type-sha256，正文任一字节改变即产生不同版本；固定索引摘要不匹配会拒启。原四份草稿保留为非当前历史稿，四份事实补充稿为当前 DRAFT。用户选择“个体工商户方向，其余信息先占位”只用于草稿方向，未核验登记，operatorName/contact/retentionRule 仍为空，不编造年限或责任承诺。

Formal-enabled 默认 false；即使打开，当前稿未经 APPROVED 审核或仍有占位也会拒启。审核元数据、真实主体/联系渠道和隐私保留规则必须完整，生效时间未到不能确认。正文版本及状态以打包资源为正本，没有发布/修改 HTTP 入口；已记录正文快照只追加，不覆盖，冲突检测失败则不写确认。旧版本可读取，不能用于接受当前条款。

事件分别为 TERMS_ACCEPTANCE、PRIVACY_NOTICE_ACKNOWLEDGEMENT，来源 LOGIN_CLICK 或 EXPLICIT_ACTION；隐私告知确认不表示所有信息处理获同意。登录点击固定当时版本，微信 code 回来后不能偷换版本。后端重新验证 audience、类型、当前版本与启用状态，先验证版本再交换微信 code，再按实际登录身份与服务端时间写入正文快照/事件，事务失败不留半套事件。重复确认保持原行和原时间。客户端不能覆盖 actor/time/body；不新增 IP、设备指纹、JWT/openid 证据字段；微信平台授权仍独立。

协议字段可选，缺字段不伪造历史接受；开发登录、刷新、只读协议不写记录。尚无 staff 行的 UNSELECTED 登录仅返回未记录状态，未选身份白名单没有扩展。未来正式上线的旧客户端/历史用户重新告知安排仍待 C-09，当前基础设施不冒充其已完成。

`scripts/sync-agreement-drafts.js` 从正文正本生成两端离线草稿；`--check` 检查精确镜像。两端 JSON 镜像保留，两端另生成同正文的 `data/agreement-drafts.js` 供原生 JavaScript 模块加载，不能手改镜像。当前版本页面失败只回退匹配版本的未启用草稿，指定其他版本时显示失败重试，不展示不同正文。两端登录目录损坏或失败会退回草稿，不沿用先前可确认版本；协议阅读没有接受按钮或认证写入。

## 本人资料请求

`app.account-data-requests.enabled` 默认 false。开启但 `intake-owner`/`intake-contact` 为空或占位则拒启，未确认受理人和真实渠道之前不开放。类型 ACCESS / CORRECTION / EXPORT / DELETION / CLOSURE 仅表达请求意图，不能当作已执行结果。当前没有站长或运营处理权限/入口。

身份只取已认证的真实 customer/staff，正数标识且行存在；每条读取、幂等查询与唯一键均按 actor_type、actor_id 隔离。提交键必传，同键相同内容返回原记录，同键内容变化拒绝；并发重复插入后使用当前加锁读校验内容。暂停受理后仍能查询本人历史或重试已登记的相同请求。记录查询按 id 游标分页，不因列表上限漏掉旧记录。

CLOSURE 客户详情附当前注销前检查，检查失败/有未结事项不拒绝登记，不作为永久障碍或删除许可。员工不套用客户检查；明确员工清结需人工核实，不能声称完成。资料页不确定提交结果时保留原键和内容，重试原申请；账户切换清理原意图并忽略迟到结果，隐藏/返回后在途请求完成可释放界面锁，历史查询失败不会显示“暂无记录”。
